A simple command-line Tic-Tac-Toe game written in Python.
## Features
- Play against the computer or another player
- Choose your letter (X or O)
- Board managed with a Python list
- Functions for checking position availability, win, and draw
- Computer opponent with simple smart moves (win, block, center, random)
- Option to play another game at the end
## How to Run
1. Install Python 3
2. Run:
   python tictactoe.py
